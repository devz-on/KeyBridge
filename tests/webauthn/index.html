Test the whole bridge.

Ask Windows for a real security-key credential, then verify its assertion signature locally.

This is a test harness, not a production relying party or server login.

Public credential state lives only in this page’s memory. No data is sent to a cloud service. Requests use localhost, ES256, and required user verification.

Before you start

  1. Connect your Android phone through USB, open KeyBridge, and start its connection service.
  2. Pair the Windows companion, start its USB/IP backend, and attach through a verified compatible signed driver.
  3. Confirm the KeyBridge FIDO HID interface in Windows. This page cannot inspect the driver or identify an authenticator from none attestation.
  4. Choose the USB security key in the Windows prompt. Inspect each request on the phone and approve it yourself.

Without an attached, working virtual key, browser use remains unverified. A successful signature alone cannot prove that KeyBridge or Android created it; confirm the phone prompt and companion activity too.
