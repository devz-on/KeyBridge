# Community standards

Discuss the work respectfully. Explain technical disagreements with evidence, give useful reproduction steps and make room for contributors with different backgrounds and levels of experience.

Harassment, threats, discriminatory remarks, doxxing and publishing another person's private information are not acceptable. Do not post credentials or sensitive authentication data, even when reporting a bug.

Maintainers may edit or remove content, close discussions or restrict participation when needed to protect contributors and keep the project usable. Decisions should be proportionate and based on conduct, not technical disagreement.

Report abusive GitHub content using GitHub's reporting tools. Security vulnerabilities belong in the project's private security-reporting channel described in SECURITY.md.
